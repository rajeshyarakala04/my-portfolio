Project 01 // FinTech & Data Visualization
Python JSON Matplotlib

Roommate Expense Splitter

Problem: Shared living arrangements frequently suffer from fragmented expense tracking, manual calculation errors, and lack of visibility into category-wise spending habits.

Solution: Engineered an automated Python CLI/analytical utility that logs shared transactions, persists structured records in JSON, computes net creditor/debtor settlements, and generates visual spending breakdowns using Matplotlib.

Key Technical Highlights
  • → Automated net-balance reconciliation algorithm minimizing peer-to-peer settlement transactions.
  • → Lightweight, fault-tolerant JSON persistence layer for historical expense auditing.
  • → Dynamic Matplotlib bar and pie charts illustrating individual contributions and category distribution.
